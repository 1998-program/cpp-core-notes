## 什么是这个工具

antigravity-awesome-skills 是一个可安装的 GitHub 技能库，收录了 1,525+ 个可复用的 SKILL.md 指导手册（Playbook），专为 Claude Code、Cursor、Codex CLI、Gemini CLI、Antigravity、Kiro 等 AI 编程助手设计，通过 `npx antigravity-awesome-skills` 一行命令即可安装到本地。

## 核心功能

- 收录 1,525+ 个覆盖开发、测试、安全、DevOps、产品和营销等领域的可复用技能
- 提供针对不同 AI 工具（Claude Code、Codex、Gemini CLI 等）的专用插件包（Specialized Plugins）
- 支持 npm CLI 安装，可通过 `--codex`、`--cursor`、`--gemini` 等标志自动放置到正确目录
- 内置 Bundle（角色推荐组合）与 Workflow（有序执行剧本），支持按类别、风险等级过滤安装
- 稳定的 Skills Manifest v1 规范，方便 AI 工具宿主集成和动态发现技能

## 适用场景

适合深度使用 Claude Code、Cursor 或 Codex CLI 的开发者与团队，通过安装现成技能库为 AI Agent 补充领域专业知识，减少重复 Prompt 编写，提升工作流的一致性与质量。
