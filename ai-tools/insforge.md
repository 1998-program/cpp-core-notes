# insforge

- **仓库**: https://insforge.dev (YC 支持，GitHub 开源)
- **Stars**: 趋势热榜（YC W26）
- **简介**: 专为 AI 编码 Agent 打造的 Postgres 一体化后端平台，集成认证、存储、计算、托管与 AI Gateway
- **主要功能**:
  - Postgres 数据库作为统一基础，所有服务在同一生态内协同
  - 内置 Auth（OAuth）、Cloud Storage、Realtime、Functions 一体化
  - 专属 AI Gateway：统一管理 AI 模型调用与配置
  - 基准测试：比 Supabase 快 1.6x、token 消耗少 30%、准确率高 1.7x
  - 支持 Stripe 支付、S3 兼容存储、数据库迁移/备份
- **适用场景**: 构建 AI 原生应用或 AI 编码 Agent 的开发者；希望用单一平台替代 Supabase + 多服务拼接方案的团队
- **推送日期**: 2026-06-09
