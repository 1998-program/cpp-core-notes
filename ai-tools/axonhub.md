# axonhub

- **仓库**: https://github.com/looplj/axonhub
- **Stars**: 3,400+
- **简介**: 开源 AI Gateway，使用任意 SDK 调用 100+ LLM，内置故障转移、负载均衡、成本控制与全链路追踪
- **主要功能**:
  - 任意 SDK（OpenAI / Anthropic / Gemini 等）透明代理，无需改代码即可切换模型
  - 智能负载均衡与自动故障转移
  - 实时成本追踪：按请求细分输入/输出/缓存 token 费用
  - 企业级 RBAC 访问控制与用量配额隔离
  - 全链路请求追踪，带线程感知可观测性
- **适用场景**: 需要多模型路由、成本管控或统一 API 接口的 LLM 应用服务端，适合个人开发者到企业团队
- **推送日期**: 2026-06-09
