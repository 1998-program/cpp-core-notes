# Dograh

**链接**: https://github.com/dograh-hq/dograh  
**分类**: 语音AI / 智能体平台 / 自托管  
**一句话描述**: 开源可自托管的语音AI平台，Vapi 和 Retell 的平替方案，2分钟内即可搭建生产级语音机器人。

## 核心功能
- **可视化工作流构建器**：拖拽式界面，无需写代码即可设计复杂对话逻辑
- **多提供商兼容**：支持自定义 LLM / STT / TTS，也可使用 Dograh 自带的推理栈
- **电话集成**：支持入站和出站电话，集成 Asterisk ARI、Twilio 等电话平台
- **MCP 原生支持**：内置 Model Context Protocol，轻松接入外部工具
- **WebRTC 实时通话**：基于 TURN Server 的 NAT 穿透，实现 100ms 级端到端延迟
- **多语言支持**：支持 30+ 种语言的语音识别与合成

## 技术亮点
- **全栈开源**：BSD 2-Clause 协议，每一行代码完全透明、可修改
- **单命令部署**：`docker compose up` 即可启动全套服务，首次约 2-3 分钟下载镜像
- **极低延迟架构**：全双工流式音频管道，打破"等整句话说完再处理"的传统串行架构，实现毫秒级 Barge-in（用户打断响应）
- **YC 校友团队**：由 YC Alumni 和成功退出的创始人维护，持续承诺保持语音 AI 开放性
- **无遥测可选**：设置 `ENABLE_TELEMETRY=false` 即可完全关闭匿名数据上报
- **七层架构**：从 WebRTC 网关、流式 VAD、JSON-RPC 状态管理到模型 Fallback，层次分明

## 适用场景
- **客服自动化**：24/7 处理常见客服咨询，转接复杂问题给人工
- **销售外呼**：自动化潜客资质筛选和外呼活动
- **预约管理**：医疗、地产等行业的预约调度语音机器人
- **企业内部 IVR**：替换传统交互式语音应答系统
- **隐私敏感场景**：数据完全在自有服务器，满足 GDPR / HIPAA 合规要求

## 快速上手

**1. 一键启动（本地）**
```bash
curl -o docker-compose.yaml https://raw.githubusercontent.com/dograh-hq/dograh/main/docker-compose.yaml
REGISTRY=ghcr.io/dograh-hq ENABLE_TELEMETRY=true docker compose up --pull always
```

**2. 访问 Web 界面**
- 打开 http://localhost:3010
- 选择 Inbound 或 Outbound 模式
- 给机器人命名，填写用例描述（5-10词）
- 点击 **Web Call** 即可直接测试

**3. 与 Vapi / Retell 对比**

| 对比维度 | Dograh | Vapi | Retell |
|---|---|---|---|
| 开源协议 | BSD 2-Clause ✅ | 专有 ❌ | 专有 ❌ |

| 定价 | 自托管免费 | 按分钟计费 | 按分钟计费 |
| 自带 LLM/TTS/STT | 任意提供商 ✅ | 有限集成 | 有限集成 |
| 数据主权 | 完全自有 ✅ | 对方云端 | 对方云端 |
