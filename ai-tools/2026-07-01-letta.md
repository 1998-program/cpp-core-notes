## 核心使用场景

### 1. 长期陪伴型 AI 助手

**场景描述**：用户希望 AI 记住过去几个月甚至几年的对话内容、个人偏好、工作习惯。

**传统痛点**：
- 每次 new chat = 清空记忆
- 无法记住用户的名字、生日、工作内容
- 上下文窗口有限，几天前的对话就忘了

**Letta 解决方案**：
```python
from letta_client import Letta

client = Letta(api_key=os.getenv("LETTA_API_KEY"))

# 创建带记忆的代理
agent = client.agents.create(
    model="openai/gpt-5.2",
    memory_blocks=[
        {
            "label": "human",  # 用户画像内存块
            "value": "Name: 胡纪阳. 公司: 百度. 部门: 推荐融合组. 座位: K1-F3-A-081."
        },
        {
            "label": "persona",  # 代理人格内存块
            "value": "我是罗氏虾，一只热心的小龙虾助手，记住主人的所有偏好和习惯。"
        }
    ],
    tools=["web_search", "fetch_webpage"]  # 内置工具
)

# 任何时候问 "我是什么部门的？" 都能回答
response = client.agents.messages.create(
    agent_id=agent.id,
    input="你还记得我在哪个部门工作吗？"
)
# 输出：记得！您在百度推荐融合组工作，座位号是 K1-F3-A-081。
```

**核心价值**：**一次记忆，永久保持**。AI 会自动更新 `human` 内存块，无需每次重复说明。

- 不学习用户的编码偏好

**Letta 解决方案**：
```python
# Letta Code CLI - 本地运行带记忆的代码代理
```

**内存结构示例**：

**核心价值**：**AI 越用越懂你**，像真正的助手一样积累经验。

### 3. 企业知识库问答 + 多轮对话保持

**场景描述**：企业内部知识库问答系统，需要在多轮对话中保持上下文，记住用户之前问过什么。

**传统方案问题**：
- RAG 系统通常"无状态"，每次 query 独立
- 无法记住用户 5 分钟前问的相关问题
- 无法构建"对话历史"的知识图谱

**Letta 解决方案**：
```python
# 1. 上传企业文档到 Archival Memory
client.agents.sources.attach(
    agent_id=agent.id,
    source_id="internal-wiki-source"
)

# 2. 多轮对话示例
# 用户: "brpc 的 bthread 是什么？"
# AI: 解释 bthread...

# 5分钟后用户: "它和 Go goroutine 有什么区别？"
# AI: (记得上下文) bthread 是 M:N 协程，与 goroutine 的区别是...

# 第二天用户: "上次我们讨论的 bthread，有性能测试数据吗？"
# AI: (从 Recall Memory 检索) 您昨天问过 bthread，这是相关性能数据...
```

**内存层次架构**：
```
┌─────────────────────────────────────────────────────────┐
│ Core Memory (上下文窗口内)                                │
│ - 用户基本信息                                            │
│ - 当前对话焦点                                            │
│ - 代理人格设定                                            │
│ 容量: ~2000 tokens                                       │
└─────────────────────────────────────────────────────────┘
                           ↓ 溢出后归档
┌─────────────────────────────────────────────────────────┐
│ Archival Memory (向量数据库)                              │
│ - 历史对话摘要                                            │
│ - 外部知识库文档                                          │
│ - 向量化后的语义记忆                                      │
│ 容量: 无限 (按需检索)                                     │
└─────────────────────────────────────────────────────────┘
                           ↓ 关键事件提取
┌─────────────────────────────────────────────────────────┐
│ Recall Memory (时间线索引)                                │
│ - 对话时间线                                              │
│ - 关键决策点                                              │
│ - 用户反馈历史                                            │
└─────────────────────────────────────────────────────────┘
```

**核心价值**：**企业级知识问答不再是"失忆症患者"**，真正理解上下文。

### 4. 多 Agent 协作中的状态共享

**场景描述**：多个 AI Agent 协作完成任务，需要共享状态、记忆、进度。

**传统痛点**：
- 每个 Agent 独立无状态
- 协作时需要反复传递上下文
- 无法共享"团队记忆"

**Letta 解决方案**：
```python
# 创建共享内存块
shared_memory = client.blocks.create(
    label="project-state",
    value="项目进度: 完成 60%. 当前阶段: 性能优化. 待办: 压测报告."
)

# 多个 Agent 共享同一内存块
agent_a = client.agents.create(
    model="openai/gpt-5.2",
    memory_blocks=[shared_memory],  # 引用共享块
    tools=["code_review"]
)

agent_b = client.agents.create(
    model="openai/gpt-5.2",
    memory_blocks=[shared_memory],  # 同样的共享块
    tools=["performance_test"]
)

# Agent A 更新进度 → Agent B 立即看到
client.agents.messages.create(agent_a.id, input="代码审查完成，进度更新到 70%")
# Agent B 可以读取到更新后的进度
```

**核心价值**：**Agent 团队协作的"共享大脑"**，状态实时同步。

## 技术架构深度解析

### 1. 三层内存架构设计

Letta 的核心创新是**仿人类大脑的多层记忆系统**：

```
┌─────────────────────────────────────────────────────────┐
│                   Core Memory (工作记忆)                 │
│                                                          │
│  Block {                                                 │
│    label: "human"        // 用户画像                     │
│    value: "姓名: 胡纪阳..."                              │
│    limit: 2000 chars                                     │
│  }                                                       │
│                                                          │
│  Block {                                                 │
│    label: "persona"      // 代理人格                     │
│    value: "我是罗氏虾..."                                │
│  }                                                       │
│                                                          │
│  特点:                                                   │
│  - 始终在 LLM 上下文窗口内                               │
│  - Agent 可直接读写（通过内置工具）                      │
│  - 容量有限但访问速度最快                                │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│              Archival Memory (语义长期记忆)              │
│                                                          │
│  PassageManager {                                        │
│    - 向量数据库存储 (PostgreSQL pgvector / Qdrant)       │
│    - 自动 Embedding (OpenAI text-embedding-3-small)      │
│    - 语义相似度检索                                      │
│  }                                                       │
│                                                          │
│  存储内容:                                               │
│  - 对话摘要                                              │
│  - 外部文档                                              │
│  - Agent 自主生成的笔记                                  │
│                                                          │
│  检索工具: `conversational_memory_search`               │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│              Recall Memory (情景记忆)                    │
│                                                          │
│  MessageManager {                                        │
│    - 完整对话历史                                        │
│    - 时间线索引                                          │
│    - 按 timestamp 检索                                   │
│  }                                                       │
│                                                          │
│  查询示例: "上周二我们讨论了什么？"                       │
└─────────────────────────────────────────────────────────┘
```

**核心代码实现**（`letta/schemas/memory.py`）：
```python
class Memory(BaseModel):
    """代理的上下文内存（Core Memory）"""

    blocks: List[Block] = Field(..., description="内存块列表")
    file_blocks: List[FileBlock] = Field(
        default_factory=list,
        description="附加文件的内存块"
    )

    # Agent 可通过内置工具修改这些块：
    # - core_memory_append(label, content)
    # - core_memory_replace(label, old_content, new_content)
```

### 2. 内置工具：让 Agent 自主管理内存

Letta 提供了一套**内置工具**，让 Agent 可以自主操作自己的内存：

```python
# 核心内存工具（BASE_MEMORY_TOOLS）
BASE_MEMORY_TOOLS = [
    "core_memory_append",    # 追加内容到内存块
    "core_memory_replace",   # 替换内存块中的内容
    "core_memory_insert",    # 在指定位置插入
]

# 归档记忆工具
ARCHIVAL_TOOLS = [
    "archival_memory_insert",    # 插入到长期记忆
    "archival_memory_search",    # 语义搜索
]

# 对话记忆工具
RECALL_TOOLS = [
    "conversation_search",       # 搜索历史对话
    "conversation_search_date",  # 按日期搜索
]
```

**Agent 自主记忆更新示例**：

```python
# 用户: "我今天升职了，成为技术经理"
```

### 3. 状态持久化与异步架构

Letta 使用**PostgreSQL + SQLAlchemy** 实现持久化存储：

```python
# 数据库表结构
class Block(BaseBlock):
    """内存块持久化"""
    id: str
    value: str                    # 内存内容
    limit: int = 2000             # 字符限制
    label: Optional[str]          # 标签（human/persona）
    read_only: bool = False       # 是否只读
    tags: List[str] = []          # 标签

class ArchivalPassage(Base):
    """归档记忆持久化"""
    id: str
    content: str                  # 文本内容
    embedding: List[float]        # 向量嵌入
    agent_id: str                 # 所属代理
    created_at: datetime
```

**异步服务架构**（`letta/services/`）：
```
services/
├── agent_manager.py      # Agent 生命周期管理
├── block_manager.py      # 内存块 CRUD
├── passage_manager.py    # 归档记忆 + 向量搜索
├── message_manager.py    # 对话历史管理
├── tool_manager.py       # 工具注册与执行
└── archive_manager.py    # 归档管理
```

### 4. 上下文窗口智能管理

Letta 实现了**自动上下文压缩**机制：

```python
class ContextWindowOverview(BaseModel):
    """上下文窗口监控"""

    context_window_size_max: int      # 最大 token 数
    context_window_size_current: int  # 当前 token 数

    num_tokens_core_memory: int       # 核心内存占用
    num_tokens_archival_memory: int   # 归档摘要占用
    num_tokens_messages: int          # 对话消息占用

    # 当接近上限时，自动触发压缩：
    # 1. 摘要旧消息 → 移入 Archival Memory
    # 2. 压缩 Core Memory（保留关键信息）
    # 3. 清理过期上下文
```

**压缩策略**（`letta/memory/summarize_messages`）：
```python
async def summarize_messages(
    messages: List[Message],
    target_token_count: int
) -> str:
    """将消息摘要压缩到目标 token 数"""

    # 使用 LLM 生成摘要
    summary = await llm_client.summarize(
        messages=messages,
        prompt="总结以下对话的关键信息："
    )

    # 存入 Archival Memory
    await passage_manager.insert(
        content=summary,
        metadata={"type": "conversation_summary"}
    )

    return summary
```

## 与其他框架对比

| 特性 | Letta | LangGraph | AutoGen | OpenAI Assistants API |
|------|-------|-----------|---------|----------------------|
| **持久化内存** | ✅ 三层架构 | ❌ 需自己实现 | ❌ 无内置 | ✅ 有但不可自定义 |

| **本地运行** | ✅ Letta Code CLI | ✅ 完全开源 | ✅ 完全开源 | ❌ 仅云端 |
| **模型无关** | ✅ 任何 OpenAI 兼容 API | ✅ 是 | ✅ 是 | ❌ 仅 OpenAI |

## 最佳实践建议

### 1. 内存块设计原则

```python
# ❌ 不好的设计：内容过于宽泛
memory_blocks=[{
    "label": "info",
    "value": "用户喜欢很多东西..."  # 太模糊
}]

# ✅ 好的设计：分类清晰、结构化
memory_blocks=[
    {
        "label": "human",        # 用户基本信息
        "value": "姓名: 胡纪阳\n部门: 推荐融合组\n技术栈: C++, Python"
    },
    {
        "label": "preferences",  # 偏好
        "value": "代码风格: 函数式\n喜欢: 性能优化\n不喜欢: 过度设计"
    },
    {
        "label": "project",      # 当前项目
        "value": "项目: OpenClaw\n当前任务: 插件开发\n进度: 60%"
    }
]
```

### 2. 让 Agent 主动更新内存

```python
# 在 system prompt 中引导 Agent：
```
