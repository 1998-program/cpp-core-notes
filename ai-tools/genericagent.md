# GenericAgent

- **仓库**: https://github.com/lsdefine/GenericAgent
- **Stars**: 热榜爆发（单日 800+ stars）
- **简介**: 极简自进化 Agent 框架，~3K 行核心代码，每次完成任务后自动将执行路径结晶为可复用技能，形成专属技能树
- **主要功能**:
  - 自进化技能树：每次解决新任务后自动生成 Skill，越用越强
  - 9 个原子工具 + ~100 行 Agent Loop，获得对本机的系统级控制（浏览器、终端、文件系统、键鼠、屏幕、移动端 ADB）
  - Token 高效：相比其他 Agent 框架节省 6x token 消耗
  - 兼容 Claude / Gemini / Kimi / MiniMax 等主流模型
  - 无复杂依赖，零部署开销
- **适用场景**: 希望 Agent 能自我积累能力、减少重复解题的个人/团队；自动化本地计算机任务的高效工具
