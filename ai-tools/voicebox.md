# voicebox

- **仓库**: https://github.com/jamiepine/voicebox
- **Stars**: 24,300+
- **简介**: 开源 AI 语音合成工作室，支持语音克隆、语音听写与创意语音生成
- **主要功能**:
  - 完整的语音合成工作室界面，非简单脚本或 API
  - 支持语音克隆（Clone）、语音听写（Dictate）与语音创作（Create）
  - TypeScript 编写，MIT 开源，可本地部署
  - 社区驱动，无订阅费用与使用限制
  - 提供可定制的合成参数管理
- **适用场景**: 需要本地化、可定制语音合成能力的开发者和创作者；构建播客、语音助手、配音系统等场景
- **推送日期**: 2026-06-09
