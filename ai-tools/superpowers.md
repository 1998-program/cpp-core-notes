# superpowers

- **仓库**: https://github.com/obra/superpowers
- **Stars**: 153,900+
- **简介**: 面向 AI 编码 Agent 的可组合技能框架与软件开发方法论
- **主要功能**:
  - 以"技能（Skill）"为核心的模块化框架，覆盖设计→规划→实现全流程
  - 让 AI Agent 不只是生成代码，而是遵循完整工程工作流
  - 提供初始组件加速工作流启动
  - MIT 开源，Shell 编写，轻量可嵌入
  - 支持多种 AI 编码工具（Claude Code、Codex、Cursor 等）
- **适用场景**: 希望规范 AI 编码 Agent 行为、提升代码质量与可维护性的工程团队；适合需要标准化 AI 辅助开发流程的项目
- **推送日期**: 2026-06-09
