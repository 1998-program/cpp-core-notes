## 什么是这个工具

AutoBE 是一个 AI 后端构建工具，用户只需用自然语言描述需求，系统会通过 40+ 个专业 AI Agent 协作（瀑布式流程），自动生成完整的后端应用，包含数据库设计、API 规范、E2E 测试和实现代码，并保证 100% 可编译。

## 核心功能

- 多阶段 AI Agent 协作：需求分析 → 数据库设计 → API 规范 → E2E 测试 → 代码实现
- 类型安全保障：使用语言无关的 AST 生成，每个节点经过类型验证，确保生成代码 100% 可编译
- 自动生成类型安全的客户端 SDK，支持 React/Vue/Angular 等框架零配置接入
- 内置基准测试（Benchmark）评估 13+ LLM 模型在 4 种项目类型上的表现
- 支持本地模型（如 Qwen3）和主流云端 LLM 提供商

## 适用场景

适合快速原型开发或需要从自然语言描述直接生成后端服务的团队，尤其适合不熟悉后端开发的产品团队或需要快速验证 MVP 的初创公司。

## 亮点

通过语言无关的 AST 中间表示实现结构级别的类型验证，突破了传统 AI 代码生成"能跑但不对"的瓶颈，率先实现后端代码 100% 编译成功率。
