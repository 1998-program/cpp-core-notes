## 什么是这个工具

abtop 是一款类似 htop 的终端 TUI 工具，专为 AI 编程 Agent 设计。它能够实时监控 Claude Code、Codex CLI 等 AI 编码 Agent 的会话状态，包括 token 消耗、上下文窗口使用情况、速率限制以及监听端口信息。

## 核心功能

- 实时监控 AI coding agent 会话（Claude Code、Codex CLI）的 token 消耗与上下文窗口使用量
- 可视化速率限制状态，包含上下文窗口压缩检测的 context window gauge
- 子 Agent 树形视图展示，支持 session 过滤与多主题切换
- 提供 JSON snapshot API，方便集成到本地 Web 仪表板（abtop-web-ui）
- 隐私优先：只读取本地文件与进程元数据，不暴露文件内容或 prompt 文本

## 适用场景

适合频繁使用 Claude Code 或 Codex CLI 等 AI 编码 Agent 的开发者，用于实时掌握 token 消耗与速率限制，避免意外超额消费或任务中断。

## 亮点

将经典运维监控工具 htop 的设计理念移植到 AI Agent 可观测性领域，是首批专门面向 AI 编程 Agent 的终端监控工具之一。
