## 可追溯性与验证

[changes.json](changes.json) 记录每项正文清理的原因、章节名称、原文件 SHA-256 和固定提交链接。原始材料保留在 Git 历史中，未进行历史重写。现有文章文件名全部保留，因此旧文件链接仍可打开；被合并章节的旧标题锚点可能不再存在。

验证包括目录全覆盖和唯一主文、生成幂等性、相对文件链接、全文重复与高重合检测，以及迁移测试：逐篇比对退役附录前的正文不变，核对被裁剪文章的其他章节仍保留，并验证原文哈希和图解未丢失。

本次没有重新读取或运行业务服务源码，没有复测历史性能数据，也没有将旧扫描结论升级为已验证事实。其余附录保留待后续按实际源码版本复核。
